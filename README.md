## Créditos y Recursos Utilizados

### Modelos y Assets 3D (Kenney)
- Blocky Character Kit: personajes y obstáculos
- Blaster Kit (Weapons): armas y efectos
- Food Kit: alimentos y cocina
- Prototype Kit: prototipos, animales, vehículos, edificios
- City Kit (Suburban): ciudad y suburbios

Todos los assets de Kenney están bajo licencia Creative Commons CC0.
